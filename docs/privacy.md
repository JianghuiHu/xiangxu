# 隐私说明

## 本地处理

像序使用浏览器 File API、Canvas、Web Worker、IndexedDB 和 File System Access API 完成图片导入、预览、处理、缓存与导出。图片内容不会发送到像序服务器，原始文件也不会被覆盖。

用户预设、模型缓存和最近授权的文件夹句柄只保存在当前浏览器的本地存储中。清除站点数据会同时清除这些内容。

## 网络请求

基础图片处理不需要联网。仅当用户主动点击下载可选 AI 模型时，浏览器才会访问模型清单中记录的第三方托管地址；请求不包含用户图片。

VTracer、抠抠图等第三方站点如果未来以外链形式出现，将适用第三方自己的隐私政策。像序不会在后台把图片自动转交给这些服务。

## 导出权限

安全 ZIP 模式通过浏览器下载保存结果。直接写入文件夹只会在用户主动选择并授权目录后工作；浏览器不允许像序在未授权时访问任意本地路径。

## 部署说明

Vercel 等静态托管平台只提供 HTML、CSS、JavaScript、WASM 和图片资源，不参与图片处理。部署方可能按其平台政策记录常规网页访问日志，但像序代码不会把用户导入的图片发送到托管平台。
