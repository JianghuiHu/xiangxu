# AI 模型指南

AI 抠图是可选能力。没有安装任何模型时，导入、裁切、缩放、画布、蒙版、水印、预设、压缩和批量导出仍可使用。

## PP-MattingV2

- 用途：人像与发丝边缘抠图。
- 输入：固定 `1×3×512×512`。
- 本地转换权重大小：35,940,680 字节。
- SHA-256：`8286b1a110360e868d54ad00319aaa12d5e7bba79ee42e057d67fa5baa8962ff`。
- 来源与转换信息：见 `assets/models/README.md`。

该权重不进入普通 Git 历史，也不随 Vercel 部署。开发者可把已核验的文件放到：

```text
assets/models/ppmattingv2-stdc1-human-512.onnx
```

应用会通过 HTTP `HEAD` 检测文件是否实际存在；缺失时不会把模型误报为已安装。

## u2netp

- 用途：轻量通用前景分割。
- 下载大小：4,574,861 字节。
- SHA-256：`309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`。
- 下载地址记录在 `models/model-manifest.json`。

用户选择 u2netp 并点击下载后，文件会先完成哈希和模型结构检查，再写入浏览器 IndexedDB。下载可以取消；单次失败不会影响基础处理。

## 删除与重装

已下载模型可从模型区删除。删除会释放当前推理会话并移除 IndexedDB 缓存；再次点击下载即可重新安装。

## 许可证

ONNX Runtime Web、模型代码许可证和模型权重许可证彼此独立。发布模型附件前必须再次核实原始来源、转换链路和再分发条件。
