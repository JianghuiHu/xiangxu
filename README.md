# 像序 Xiangxu

> 万象归序，创作从容。

像序是一款面向设计师与内容创作者的本地优先图片批处理工作台。它可以导入、处理和检查图片，批量导出常用格式、预设及 Sprite 开发素材，并提供可选的本地 AI 抠图扩展。

## 在线使用

[打开像序网页版](https://xiangxu.vercel.app)

部署配置见 [docs/deployment.md](docs/deployment.md)。

## 隐私说明

图片通过浏览器原生文件接口读取，只存在于当前浏览器会话，不会上传服务器，也不会修改原始文件。AI 抠图同样在本机通过 ONNX Runtime Web 执行；只有用户主动点击“下载模型”时才会联网获取 ONNX 模型，图片数据不会随该请求发送。

## 启动方式

1. 双击项目根目录的 `start.bat`。
2. 脚本会优先调用 Windows 的 `py`，其次调用 `python`，在 `http://localhost:5173` 启动本地服务器并打开浏览器。
3. 关闭命令窗口会停止工具。

无需 `npm install`。启动脚本优先使用 Python 3；没有 Python 时会自动使用 Windows PowerShell。

### Windows EXE 版

直接双击 `像序.exe` 即可打开独立桌面窗口，不需要安装 Python 或 Node.js。程序使用系统 WebView2 运行，图片和预设仍只保存在本机；单文件 EXE 首次启动时需要数秒解压运行组件。

当前 EXE 未使用商业代码签名证书；首次从网络下载后，Windows SmartScreen 可能显示未知发布者提示。

## 浏览器要求

推荐最新版 Chrome 或 Edge。文件夹导入使用 Chromium 浏览器支持的目录选择能力；剪贴板按钮可能要求浏览器授权，也可以直接在页面中按 `Ctrl+V`。

## 目录结构

- `index.html`：应用入口与三栏页面结构。
- `css/`：重置、设计令牌、布局、组件及工具样式。
- `js/state/`：默认状态、Store 和状态动作。
- `js/import/`：文件、文件夹、拖放、剪贴板导入和图片解码。
- `js/ui/`：图片列表、预览、折叠设置与消息提示。
- `js/ai/`：可选的模型管理、ONNX 会话缓存和本地背景移除模块。
- `js/render/`、`js/processing/`、`js/export/`、`js/presets/`、`js/inspection/`：像素处理、导出、预设和检查模块。
- `workers/`：文件哈希等耗时任务的 Worker。
- `tests/fixtures/`：去边、透明和重复检测回归夹具。
- `vendor/`：本地第三方运行时；当前包含 ONNX Runtime Web 的 CPU/WASM 最小构建。
- `assets/`：本地图标与静态资源目录。
- `models/`：可选 AI 模型公开清单，不包含权重。
- `docs/`：隐私、模型指南和正式截图。

- 多选文件导入、文件夹选择、图片与文件夹拖放、剪贴板粘贴。
- PNG、JPG/JPEG、WebP、BMP、SVG、GIF 第一帧解码。
- 图片名称、尺寸、文件大小、格式与透明通道信息。
- 图片搜索、排序、选择、删除、清空与新建任务。
- 单图 Canvas 预览、棋盘/白/黑背景切换与缩放。
- 模块化状态管理、对象 URL 回收和中文错误提示。
- 原图与处理后预览切换。
- 固定输出尺寸与 Contain、Cover、Stretch 三种真实缩放模式。
- 高质量、标准和快速三档 Canvas 插值设置。
- 独立固定画布尺寸、透明背景与纯色背景。
- 统一边距、九宫格定位及 X/Y 像素偏移。
- 大尺寸目标预览自动降采样，界面仍显示真实目标尺寸。
- 基础设置一键恢复默认。
- 1:1、4:3、16:9、9:16 固定比例裁切。
- 可设置宽高百分比的自由裁切。
- 预览中拖动图片、滚轮缩放及双击恢复裁切位置。
- 三分法、九宫格辅助线和关闭辅助线。
- 矩形、正方形、圆形、椭圆、圆角矩形和胶囊形蒙版。
- 蒙版外区域保持透明，纯色画布只在蒙版内部填充。
- PNG、JPG、WebP 正式目标分辨率编码。
- JPG/WebP 质量设置与 JPG 背景颜色扁平化。
- 文件名模板、序号起始值、自动补零和非法字符清理。
- 批次内及目标文件夹现有文件名防重名。
- 完全本地的 ZIP 生成，无第三方运行时依赖。
- File System Access API 文件夹写入及不可用时 ZIP 回退。
- 批量任务进度、已完成/失败/待处理计数、暂停、继续、取消和日志。
- 单张编码或写入失败时继续处理其他图片。
- IndexedDB 持久化用户预设，并在不可用时自动回退 localStorage。
- 六个系统预设，以及预设搜索、收藏、最近使用、应用和删除。
- 保存新预设、覆盖当前用户预设、JSON 文件/文本导入和单预设 JSON 导出。
- 自动裁除透明边缘、白色或指定颜色边缘。
- 按主体最大宽高占比统一视觉尺寸。
- 近似颜色替换、选取任意颜色转透明、灰度、反白及基础色彩调整。
- 文字和本地图片水印、位置、透明度与平铺。
- JPG/WebP 目标 KB 压缩和可选降分辨率。
- 左右对比预览、设置撤销/重做与自定义裁切比例。
- 文件检查、Worker 完全重复检测、基础相似图片检测和 Markdown 报告。
- Sprite Sheet，以及可直接使用的 JSON、CSS、Markdown 素材清单。
- 独立流程概览、内容尺寸/最终画布职责说明和统一九宫格定位。
- Sprite 自动行列、2 的幂补齐、排序、透明/纯色背景和自定义基础文件名。
- 顶部当前预设可直接命名或重命名；流水线明确显示已开启/已关闭并可跳转到对应设置。
- 布尔设置采用开关外观并保留无障碍 checkbox 语义；低频设置默认折叠以缩短操作路径。
- 新任务保持“新建任务”置灰；导入图片、修改参数或应用预设后才可新建。
- 默认使用安全 ZIP 导出；处理完成后显示绿色保存按钮，由用户明确点击保存，避免嵌入式宿主被系统文件弹窗或强制下载中断。直接写入文件夹保留为高级模式，仅复用已明确授权的目录。
- 可选 AI 抠图位于流水线首端；PP-MattingV2 人像 512 可由本地发行包提供，u2netp 作为可选通用模型由用户主动下载。GitHub/Vercel 源码不提交模型权重。
- AI 模型首次启动不自动下载；模型与推理会话按需加载并缓存，基础图片处理不依赖 AI。
- AI 首次推理显示分阶段进度和预览遮罩；同一图片的 Mask 会按模型缓存，连续参数输入合并刷新，避免重复执行完整推理。
- AI Mask 支持独立的边缘羽化、向内收缩/向外扩展，以及逐图“增加区域/减少区域”画笔；手工笔触参与实时预览、撤销/重做和正式导出，但不会写入用户预设。
- 顶部只保留任务、历史和预设操作；“打开预设”“保存预设”位于最右并采用不同颜色，导出统一从右栏底部执行。
- 每张图片可在“统一设置 / 自定义设置”之间切换；自定义参数独立参与实时预览、检查、Sprite 与批量导出，左侧支持按设置模式筛选。

## 使用说明

- 点击“添加图片”或“添加文件夹”，也可把文件或文件夹拖入页面。
- 在页面中按 `Ctrl+V` 可追加剪贴板图片。
- 点击左侧条目切换中间预览；滚轮或工具栏按钮可缩放。
- 预览工具栏右侧可把当前图片转为“自定义设置”；切换时会复制当时的统一参数，之后的修改只影响该图。恢复统一会清除该图独立参数并立即采用最新统一设置，且支持撤销。
- 在右侧启用“统一输出尺寸”，设置宽高并选择 Contain、Cover 或 Stretch。
- 启用“固定画布”后可单独设置最终画布尺寸及透明/纯色背景。
- 使用九宫格、统一边距和 X/Y 偏移调整图片在画布中的位置。
- 启用裁切后可选择固定比例或自由宽高；在预览中拖动图片、滚轮缩放，双击恢复默认焦点。
- 启用形状蒙版后选择目标形状；圆角矩形可设置半径，胶囊形会自动计算圆角。
- 在“输出与压缩”中选择 PNG、JPG 或 WebP；JPG/WebP 可调编码质量，JPG 必须设置扁平背景颜色。
- 命名模板支持 `{原文件名}`、`{序号}`、`{宽度}`、`{高度}`、`{格式}`、`{日期}` 和 `{时间}`。
- 默认选择“安全 ZIP”后点击“开始处理并导出”，生成完成后再点击绿色保存按钮；桌面封装版使用原生保存桥接。
- “直接写入已授权文件夹”为高级模式：仅在浏览器已获得目录授权时直接写入；没有可复用授权时自动安全回退 ZIP。网页无法在未经用户授权时固定写入任意系统路径。
- “AI 一键抠图”可使用本地发行包附带的 PP-MattingV2；也可选择 u2netp 并点击下载。没有模型时 AI 自动关闭，其他处理流程不受影响。
- PP-MattingV2 约 34.3 MB，固定 512×512 输入，主要适合人物与发丝边缘；它不是通用商品、动物或任意物体分割模型。
- 边缘扩缩使用负值内缩、正值外扩；画笔模式会自动切换到处理后预览，滚轮仍可缩放查看细节。画笔数据只属于当前图片，点击“清除当前图笔触”不会删除 AI 自动 Mask。
- 底部任务栏可暂停、继续、取消并查看逐文件日志。
- 顶部“原图 / 处理后”可用于核对变换效果。
- 顶部“打开预设”可浏览六个系统预设和用户预设；支持搜索、收藏、最近使用、应用与删除。
- 顶部“保存预设”可新建用户预设；应用用户预设后再次保存可选择覆盖原记录。
- 预设只保存统一设置，不包含图片 ID、文件名或单图自定义参数；应用预设时已有自定义图片默认保持不变。
- 点击顶部“当前预设”的名称可直接命名；已有用户预设可在同一入口重命名并覆盖，不会产生重复记录。
- 右栏“预设”区域支持粘贴 JSON 或读取 `.json` 文件，也可导出当前设置。
- “自动去边”可选择透明边或白色/指定颜色边，容差与额外边距会实时进入预览。
- “内容尺寸”控制图片在画布内的包围盒；“最终画布”控制导出文件尺寸，两者可组合而不是重复设置。像素尺寸和主体百分比同时启用时取更严格限制。
- 流水线节点会显示“已开启/已关闭”；关闭项置灰，点击节点可展开并定位对应设置。
- “主体尺寸统一”“颜色处理”和“水印”均同时作用于预览与正式导出。
- 颜色处理会根据模式显示必要字段：近似替换显示来源色和目标色；颜色转透明只显示要透明化的颜色；灰度、反白与仅参数模式不显示无关颜色项。
- 图片水印支持本地 PNG、JPG、WebP、SVG Logo；文件数据会随用户预设保存在浏览器本地。
- 目标体积适合 JPG/WebP；启用“允许降低分辨率”后会在最低质量仍超标时逐级缩小。
- “文件检查”生成队列问题报告；“Sprite Sheet”导出 PNG、JSON、CSS 和 Markdown 的 ZIP。
- Sprite 可自动计算接近正方形的行列，或指定列数；WebGL 场景可启用 2 的幂画布补齐。
- 勾选条目后可批量删除。清空和新建任务会二次确认。

## 常见问题

**双击 `index.html` 为什么不能正常运行？**  项目使用 ES Modules，请通过 `start.bat` 的本地 HTTP 服务运行。启动器优先使用 Python，没有 Python 时会自动回退到 Windows PowerShell，无需另外安装依赖。

**图片会发送到网络吗？**  不会。核心导入、预览和 AI 推理均在本机完成。只有主动下载 AI 模型时会访问模型托管地址，该请求不包含图片。

**剪贴板按钮无法读取？**  浏览器可能拒绝主动读取权限，请保持页面聚焦后直接按 `Ctrl+V`。

## 已知限制

- GIF 仅解码第一帧；动态 WebP 是否为动画暂不做完整帧检测。
- 透明通道检测会将图片降采样到最多 256×256；极小范围透明像素可能漏检。
- 预览最长边会降采样到 2048px 以控制内存；原始文件未被修改。
- Canvas 预览最长边限制为 2048px；正式导出会使用目标分辨率重新渲染。
- 自由裁切范围目前通过宽高百分比设置，尚未提供拖动裁切边框手柄。
- JPG 输出会自动使用用户选择的背景颜色扁平化透明区域。
- ZIP 当前使用标准 Store 模式，不进行二次 Deflate 压缩；图片本身已经是压缩格式，因此可避免额外 CPU 消耗。
- 暂停和取消在当前单张编码结束后生效，无法中断浏览器正在执行的单次 `canvas.toBlob()`。
- 基础相似检测采用 16×16 平均哈希，对旋转、裁切或大幅调色图片的识别有限。
- PNG 原生编码没有质量参数，目标 KB 模式只能在允许时通过降低分辨率继续逼近。
- 内置浏览器不再从主导出按钮自动唤起文件夹选择器；无目录授权时已验证安全回退 ZIP。直接文件夹写入需在支持 File System Access API 的独立 Chrome/Edge 中由用户明确授权。
- EXE 版依赖 Windows WebView2 Runtime；Windows 10/11 通常已随 Microsoft Edge 安装。若精简系统缺少 WebView2，可改用 `start.bat` 浏览器版。
- AI 抠图当前固定使用 CPU/WASM 后端，首次模型下载、校验和推理仍会有等待；界面会显示加载阶段，后续调整优先复用 Mask 缓存。
- 文件夹选择器必须由真实用户点击触发，自动化环境无法代替用户完成系统目录授权。

## 第三方依赖及许可证

浏览器版本不使用 CDN、远程字体或远程图标。可选 AI 扩展在 `vendor/onnxruntime-web/` 内置 ONNX Runtime Web 1.27.0 的 CPU/WASM 最小运行时（MIT）；GitHub/Vercel 源码不包含 PP-MattingV2 或 u2netp 权重。u2netp 仅在用户主动点击下载后保存到浏览器 IndexedDB。EXE 封装使用 Python、PyInstaller 与 pywebview；应用内 ZIP 由项目模块使用标准 ZIP Store 结构生成。详见 `THIRD_PARTY_NOTICES.md`。
