# 像序 macOS 版 1.2.5

> 万象归序，创作从容。

## 启动

1. 解压 ZIP，不要直接在压缩包预览中运行。
2. 双击 `start.command`。
3. 默认浏览器会自动打开像序；端口会自动选择，避免与其他程序冲突。
4. 关闭启动时出现的终端窗口即可停止像序。

像序在本机浏览器中运行，图片不会上传。首次运行需要系统中已有 Python 3；如果没有，请从 Python 官网或 Homebrew 安装。

如果 macOS 阻止首次运行，可在“系统设置 → 隐私与安全性”中允许，或在终端进入解压目录后运行：

```bash
chmod +x start.command
./start.command
```

## AI 抠图

- PP-MattingV2 基础模型已包含在压缩包内，无需联网即可使用。
- u2netp 是可选模型，不包含模型权重；选择后需要由用户自行下载。
- 模型推理在本机完成，不上传图片。

## 浏览器与导出

建议使用最新版 Chrome 或 Edge。Safari 不支持直接写入文件夹时，像序会回退为下载 ZIP 文件。

## 平台说明

此包不是已签名的原生 `.app` 或 `.dmg`。当前发布环境为 Windows，无法可靠地跨平台构建、签名和公证 macOS 原生应用；此离线浏览器包保留相同的图片处理功能。
